# Инспектрон — корпоративный сайт производителя анализаторов воздуха

Статический сайт российского производителя анализаторов качества воздуха
(ООО «Инспектрон», г. Новосибирск). Линейка продукции: **Инспектрон-100**,
**Инспектрон-200**, **Инспектрон-300** и флагманская модель **Инспектрон A8 Pro**.

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Главная: преимущества, сравнение моделей, примеры внедрения, форма запроса КП |
| `catalog.html` | Каталог с таблицей сравнения и наличием на складе |
| `det100.html`, `det200.html`, `det300.html`, `a8-pro.html` | Карточки моделей: характеристики, схема подключения, документация, форма КП |
| `about.html` | О компании: история, производство, сертификаты |
| `service.html` | Сервис: калибровка, поверка, гарантия, FAQ |
| `contacts.html` | Контакты, реквизиты, карта |
| `docs/inspektron-catalog-2026.pdf` | Каталог продукции (PDF) для скачивания |
| `docs/catalog.html` | Реестр документации (паспорта, протоколы поверки, сертификаты) |
| `css/`, `js/`, `fonts/`, `img/` | Стили, скрипты, самохостируемые шрифты, изображения |

## Особенности реализации

- Формы заявок отправляются через Formspree с редиректом на `thank-you.html`;
  события `submit_form`, `click_phone`, `click_download_pdf` отправляются в Яндекс.Метрику (id 108394825).
- Шрифты Inter и JetBrains Mono самохостятся (`css/fonts.css`), внешних CDN нет — сайт работает
  в российском сегменте сети без деградации оформления.
- Разметка schema.org: `Organization`, `WebSite`, `Product` (с ценой и наличием), `FAQPage`.
- Адаптив: таблицы с горизонтальным скроллом, мобильное меню, sticky-шапка.

## Публикация

Хостинг — статический (GitHub Pages / любой веб-сервер), домен `inspektron.ru` (см. `CNAME`).
